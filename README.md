### About

I work in offensive security at **NRI SecureTechnologies, Ltd.**, with interests spanning security assessments, AI security, and vulnerability management.

My research focuses on making complex security risks **visible, explainable, and actionable** — from AI supply chains and agentic systems to evidence-driven vulnerability triage.
